# WSC 2024 Reproduction Outputs

This folder contains the scriptable reproduction path for the paper-facing 5-node manufacturing demo.

```bash
python scripts/reproduce_wsc2024.py
```

The `outputs/` directory is populated with:
- `buffer_levels.csv`
